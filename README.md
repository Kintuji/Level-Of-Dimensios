Level Of Dimensions is a FPS game with puzzles and enemies, which the player need to won the levels to reach a portal that will lead him to it's dimension

This project made me grow on some some aspects:

Optimization - using the profile tool that unity provides. Understanding that, all the other levels were running even when the player was only on the first level.
Rendering Occlusion - learning how does it work and implemanting that
Lightining - working with baked lightning to optimize at maximum
